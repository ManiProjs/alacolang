01 — THE LANGUAGE

Small surface.
Real capabilities.

Alaco aims to keep its syntax approachable while giving you useful tools for everyday programs. Its compiler checks your code before it generates a target.

✓

Catch mistakes early

Names and types are analyzed before code generation, with diagnostics designed to point you toward the problem.
